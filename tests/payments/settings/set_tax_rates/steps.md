# Set Tax Rates

## Objective
Configure tax rates in Payments settings and verify they apply to new invoices.

## Prerequisites
- Access to Payments settings
- No payment gateway connected

## Steps
1. Navigate to Payments settings
2. Open tax configuration
3. Add or update a tax rate
4. Enter tax name
5. Enter tax rate value
6. Save settings
7. Verify the saved tax values are shown in settings

## Expected Result
- Tax rate is saved
- Tax name and tax rate persist after save

## Context Updates
- Save `configured_tax_name` and `configured_tax_rate`
