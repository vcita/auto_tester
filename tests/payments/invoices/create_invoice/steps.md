# Create Invoice

## Objective
Create a new invoice with line items and tax.

## Prerequisites
- Access to Invoices
- No payment gateway connected

## Steps
1. Navigate to Invoices
2. Click "Create Invoice"
3. Select or create a client
4. Add line items and tax
5. Save the invoice

## Expected Result
- New invoice appears in the invoices list
- Invoice details show correct totals and tax

## Context Updates
- Save `created_invoice_id`, `created_invoice_number`, `created_invoice_amount`
