# Sales Setup

## Objective
Log in and create the shared catalog used by all estimate tests.

## Steps
1. Log in with the configured account.
2. Create a priced service ($100) via API.
3. Create a product ($10, with description) via API.
4. Create a tax (13%) via API.

## Context Updates
- `sales_service_name`, `sales_service_price`
- `sales_product_name`, `sales_product_description`, `sales_product_price`
- `sales_tax_name`, `sales_tax_rate`
