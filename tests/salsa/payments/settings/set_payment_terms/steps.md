# Set Payment Terms

## Objective
Configure default payment terms and verify they appear on new invoices.

## Prerequisites
- Access to Payments settings
- No payment gateway connected

## Steps
1. Navigate to Payments settings
2. Open payment terms settings
3. Set default terms (e.g., due on receipt, net 7)
4. Save settings
5. Create a new invoice and verify terms are applied

## Expected Result
- Payment terms are saved
- New invoice shows the configured terms

## Context Updates
- Save `configured_payment_terms`
