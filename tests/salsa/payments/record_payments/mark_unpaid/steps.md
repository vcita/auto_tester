# Mark Unpaid

## Objective
Mark a recorded payment as unpaid and verify status and balance updates.

## Prerequisites
- An invoice with a recorded payment exists
- No payment gateway connected

## Steps
1. Navigate to the invoice details
2. Locate the recorded payment
3. Select "Mark as unpaid"
4. Confirm the action

## Expected Result
- Payment status changes to unpaid
- Invoice balance increases accordingly

## Context Updates
- Save `unpaid_payment_status`
