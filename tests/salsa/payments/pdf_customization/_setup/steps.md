# PDF Customization Setup - Steps

## Objective
Log in to the isolated account so the PDF customization test starts from a clean, default
settings state.

## Prerequisites
- Runner created an isolated account (default US / USD).
- `context["username"]`, `context["password"]`, and `context["auto_account"]` are available.

## Steps
1. Log in to the isolated account.

## Expected Result
- The isolated account is logged in and the dashboard is ready.
- PDF customization settings are at their defaults, so the read-back assertions are deterministic.
