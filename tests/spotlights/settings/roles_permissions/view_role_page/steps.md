# Open Non-Editable Role Page

## Objective
Verify that the built-in Administrator role opens in view mode (the role cannot
be edited, so no Save action is offered).

## Prerequisites
- Logged in to the isolated account (from subcategory `_setup`).

## Steps
1. Open the Roles & Permissions settings page.
2. Open the "Administrator" role.

## Expected Result
- The role page opens in view mode: there is no Save button (the built-in role
  is non-editable).

## Context Updates
- None.
