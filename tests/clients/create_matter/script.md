## Actions

### Step 0: Ensure on dashboard (no direct URL navigation)
- **Rule**: Do not use `page.goto(base_url + "/app/dashboard")` - www/app/dashboard is unavailable.
- **Action**: If `/app/dashboard` not in `page.url`, click sidebar "Dashboard" and `page.wait_for_url("**/app/dashboard**")`.

### Step 1: Open the Add matter form (with sidebar fallback)
- **Primary path**: Look for "Quick actions" panel in dashboard content (inside angular-iframe). Use `page.get_by_text("Quick actions", exact=True)` scoped to panel, then click "Add [entity]" parent.
- **Fallback path (HEALED 2026-04-05)**: If dashboard panel doesn't load (e.g. "Hmm... something went wrong" or missing panel on auto-created accounts), click the sidebar "Quick Actions" button (`page.get_by_role("button", name="Quick Actions")`), then click "Add client" / "Add property" from the dropdown overlay.
- **Wait for**: Matter creation form/dialog to appear (inside iframe)

### Step 2: Wait for form frame
- **Action**: Poll `page.frames` for a frame containing "First Name" text
- **Timeout**: 30s total
- **Result**: Returns the frame object containing the form

### Step 3: Click "Show more" (if available)
- **Action**: Click "Show more" button if it exists in the form frame
- **Purpose**: Expands additional contact fields (Referred by, Social media)
- **Adaptive**: Skip if button doesn't exist (some verticals don't have it)

### Step 4: Fill Contact Information (adaptive)
- **First Name** (required): `get_by_role("textbox", name="First Name *")`
- **Last Name**: `get_by_role("textbox", name="Last Name")`
- **Email**: Combobox field - click textbox first, then type into combobox
- **Phone**: Try "Mobile phone" first, fall back to "Phone"
- **Address**: `get_by_label("Address").first`
- **Referred by** (if Show more was clicked): `get_by_role("textbox", name="Referred by")`

### Step 5: Fill Matter Details (if available - Property vertical only)
These fields only exist on Property/Home Services vertical accounts:
- **[Entity] address**: Try each entity name + " address"
- **How can we help you?**: Textbox
- **[Entity] type**: Listbox dropdown
- **Special instructions/requests**: Textbox
- **Private notes**: Textbox (available on all verticals)

### Step 6: Click Save
- `get_by_role("button", name=re.compile(r"Save|SAVE"))`
- Wait for redirect to `/app/clients/`
